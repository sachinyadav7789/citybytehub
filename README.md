 # CityByteHub

A Gaming Cafe Management System built to manage gaming slot bookings and cafe operations.

## Features
- Online Slot Booking
- Admin Panel
- Staff Panel
- Dashboard Analytics
- Booking History
- Student Prime Card
- Inquiry System
- Responsive Design

## Tech Stack
- HTML
- CSS
- JavaScript
- Firebase  Firestore
